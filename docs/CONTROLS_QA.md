# Keybind ба Bomber радиусын гар QA

Автомат тест: `scripts/tests/controls_bomb_smoke.gd`. График UI, бодит гар/хулгана, харагдах эффект энэ орчинд батлагдаагүй.

1. F5 → **SETTINGS → Controls**. 3D Arena, 2.5D Player 1, Player 2-ийн бүх товч харагдах, scroll ажиллах эсэхийг шалга.
2. 3D Attack товчийг `H` болгож, 3D Special-ийг мөн `H` болго. Хоёр action-ийн хуучин/шинэ товч солигдож харагдах ёстой. Esc дарж rebind цуцлахыг шалга. **RESET CONTROLS** дарж default-ууд буцсаныг шалга.
3. Нэг товчийг өөрчлөөд тоглоомыг хааж дахин нээ. Сонгосон товч хадгалагдах ёстой. Дараа нь **RESET CONTROLS** дар.
4. Floating Island 3D тулаанд хөдөлгөөн, үсрэлт, sprint, dodge, attack, block, special-ийг өөрт оноосон keyboard/mouse товчоор ажиллуул. HUD-д шинэ товчны нэр гарч байгааг шалга. Дараа нь бусад stage-ийн 2.5D тулаанд Player 1/2 товчнуудыг шалга.
5. Lizard Bomber-ийн bomb-г дайснаас ойр ба хол газарт дэлбэл. 2.4 нэгжийн харагдах тойргийн дотор HP буурч, гадна HP буурахгүй, 2.5D ба 3D effect-ийн хүрээ damage хүрээтэй таарах ёстой. Debugger-ийн error/warning-ийг тэмдэглэ.

- Шалгасан хүн, огноо, төхөөрөмж: **хүлээгдэж байна**
- Keybind UI, хадгалалт, хоёр duel-д бодит input: **хүлээгдэж байна**
- Bomb радиусын харагдах байдал ба бодит тоглолт: **хүлээгдэж байна**
- Илэрсэн асуудал: **хүлээгдэж байна**
