CHESS DUEL — PHASE 3 SOUND FIX

- WAV import used auto-detected loop and QOA compression; audio_manager set loop_mode only, not loop_end. This is a plausible cause of silent/stalled playback, not a reproduced diagnosis.
- Smoke test asserted playing, not full loop points, mixer gain or F5 scene startup.
- Parry, block, counter and regular attacks lacked differentiated event audio.

- Main menu, board move/capture, alternate duel and 3D combat event hookups.
- Existing rigs, maps, animations, test scenes and F5 entry preserved. Removed only generated .godot cache from delivery; Godot regenerates on import.
